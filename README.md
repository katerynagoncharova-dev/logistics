# Сайт логістичної компанії — перша версія

## Запуск локально

```bash
cd ~/Desktop/Logistics
node serve.mjs
```

Відкрийте http://localhost:3000. Зупинка сервера — `Ctrl + C`.

## Файли

| Файл | Призначення |
| --- | --- |
| `index.html` | Розмітка сторінки (11 секцій + футер) |
| `styles.css` | Стилі, палітра й адаптивність |
| `script.js` | Меню, підстановка послуги, перевірка форми, демо-режим. Угорі файлу — `SITE_CONFIG` (назва, телефон, email, Google-профіль, сервіс заявок) |
| `assets/` | Фото й favicon |
| `tools/generate-images.mjs` | Генерація фото через Gemini |
| `serve.mjs` | Локальний сервер без залежностей |

## Фото

У `assets/` — шість AI-фото (hero, service-ukraine, service-international, service-groupage, cta, about), стиснуті для вебу. Оригінали PNG — у `assets/source/`. Фокус кадру для обрізаних фото задано класами `.media--focus-*` у `styles.css`.

Щоб замінити фото, збережіть новий файл під тим самим іменем. За потреби перегенерації через API: `node tools/generate-images.mjs [slot]` з ключем у `.env`.

## Перед публікацією погодити з компанією

- Логотип. Назва — Veymark Logistics (`SITE_CONFIG.brandName` і текст у `index.html`); знак логотипа поки тимчасовий.
- Послуги: перевезення Україною, міжнародні перевезення, збірні вантажі. Це чернетка зі сценарію.
- Географію: Україна та Україна ↔ Європа. Карта схематична, без конкретних країн і точок.
- Контакти. Телефону й email у матеріалах немає, тому вони приховані. Після підтвердження заповніть `SITE_CONFIG.phone` / `email`.
- Відгуки Google. Додайте посилання на профіль у `SITE_CONFIG.googleReviewsUrl` або вставте віджет у `[data-reviews-widget]`. Службовий напис-заглушку приберіть перед публікацією.
- Сервіс заявок. Вкажіть URL у `SITE_CONFIG.formEndpoint`. Без нього форма працює в демо-режимі. Подія конверсії — функція `trackQuoteConversion()` у `script.js`.
- Згенеровані AI фото є ілюстративними.
